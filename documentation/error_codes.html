Error Codes

If invalid input or parameter data is passed to a planner, a non-zero error code is returned. All error codes are listed in the following table.

ValueNameDescription
0NONENo error.
1INPUT_TIMESTAMPThe input timestamp is not finite.
2INPUT_ORIGIN_LLAThe input originLLA is not finite.
3INPUT_ORIGIN_OLD_TO_NEWThe input originOldToNew is not finite.
4INPUT_INITIAL_POSEThe input initialPose is not finite.
5INPUT_INITIAL_STATE_AND_INPUTThe input initialStateAndInput is not finite.
6INPUT_INITIAL_PATHThe input initialPath is not finite.
7INPUT_FINAL_POSEThe input finalPose is not finite.
8INPUT_SAMPLING_BOX_CENTER_POSEThe input samplingBoxCenterPose is not finite.
9INPUT_SAMPLING_BOX_DIMENSIONThe input samplingBoxDimension is not finite.
10INPUT_INITIAL_POSE_NOT_INSIDE_SAMPLING_BOXThe input initialPose is not inside the sampling box.
11INPUT_INITIAL_STATE_NOT_INSIDE_SAMPLING_BOXThe input initialStateAndInput is not inside the sampling box.
12INPUT_FINAL_POSE_NOT_INSIDE_SAMPLING_BOXThe input finalPose is not inside the sampling box.
13INPUT_STATIC_OBSTACLESThe vertices of staticObstacles are not finite, not convex, or the vertex order is inconsistent.
14INPUT_MIN_TRAJECTORY_DURATIONThe input minTrajectoryDuration is not finite or is negative.
15PARAM_MODEL_MATFThe parameter matF is not finite.
16PARAM_MODEL_MATBThe parameter matB is not finite.
17PARAM_MODEL_INV_MATBThe parameter matB is not invertible.
18PARAM_MODEL_VEC_TIMECONSTANTS_XYNThe parameter vecTimeconstantsXYN is not finite or not positive.
19PARAM_MODEL_VEC_TIMECONSTANTS_INPUTThe parameter vecTimeconstantsInput is not finite or not positive.
20PARAM_MODEL_LOWER_LIMIT_XYNThe parameter lowerLimitXYN is not finite.
21PARAM_MODEL_UPPER_LIMIT_XYNThe parameter upperLimitXYN is not finite.
22PARAM_MODEL_LOWER_GREATER_UPPER_LIMITThe parameter lowerLimitXYN is greater than upperLimitXYN.
23PARAM_COSTMAP_RESOLUTIONThe parameter resolution is not finite or is too low.
24PARAM_COSTMAP_DISTANCE_SCALEThe parameter distanceScale is not finite or is negative.
25PARAM_COSTMAP_DISTANCE_DECAYThe parameter distanceDecay is not finite or not positive.
26PARAM_METRIC_WEIGHT_PSIThe parameter weightPsi is not finite or not positive.
27PARAM_METRIC_WEIGHT_SWAYThe parameter weightSway is not finite or is negative.
28PARAM_METRIC_WEIGHT_REVERSE_SCALEThe parameter weightReverseScale is not finite or is negative.
29PARAM_METRIC_WEIGHT_REVERSE_DECAYThe parameter weightReverseDecay is not finite or not positive.
30PARAM_GEOMETRY_MAX_POSITION_DEVIATIONThe parameter collisionCheckMaxPositionDeviation is not finite or is too low.
31PARAM_GEOMETRY_MAX_ANGLE_DEVIATIONThe parameter collisionCheckMaxAngleDeviation is not finite or is too low.
32PARAM_GEOMETRY_VEHICLE_SHAPEThe vertices of vehicleShape are not finite, not convex, or the vertex order is inconsistent.
33PARAM_GEOMETRY_SKELETAL_POINTSThe parameter skeletalPoints is empty or not finite.
34PARAM_PATHPLANNER_PERIOD_GOAL_SAMPLINGThe parameter periodGoalSampling of the path planner is not positive.
35PARAM_MOTIONPLANNER_SAMPLING_RANGE_POSITIONThe parameter samplingRangePosition is not finite or not positive.
36PARAM_MOTIONPLANNER_SAMPLING_RANGE_ANGLEThe parameter samplingRangeAngle is not finite or not positive.
37PARAM_MOTIONPLANNER_PERIOD_GOAL_SAMPLINGThe parameter periodGoalSampling of the motion planner is not positive.
38PARAM_MOTIONPLANNER_SAMPLETIMEThe parameter sampletime is not finite or not positive.
39PARAM_MOTIONPLANNER_MAX_INPUT_PATH_LENGTHThe parameter maxInputPathLength is not finite or not positive.
40PARAM_CONTROLLER_MAT_KThe parameter matK is not finite.
41PARAM_CONTROLLER_MAX_RADIUS_XThe parameter maxRadiusX is not finite or not positive.
42PARAM_CONTROLLER_MAX_RADIUS_YThe parameter maxRadiusY is not finite or not positive.
43PARAM_CONTROLLER_MAX_RADIUS_PSIThe parameter maxRadiusPsi is not finite or not positive.
44PARAM_CONTROLLER_MIN_RADIUS_POSITIONThe parameter minRadiusPosition is not finite or not positive.
45PARAM_REGION_OF_ATTRACTION_RANGE_POSEThe parameter rangePose is not finite or not positive.
46PARAM_REGION_OF_ATTRACTION_RANGE_UVRThe parameter rangeUVR is not finite or not positive.
47PARAM_REGION_OF_ATTRACTION_RANGE_XYNThe parameter rangeXYN is not finite or not positive.
48PARAM_ONLINEPLANNER_MAX_COMPUTATION_TIME_PATH_RESETThe parameter maxComputationTimePathOnReset is not finite or not positive.
49PARAM_ONLINEPLANNER_MAX_COMPUTATION_TIME_MOTION_RESETThe parameter maxComputationTimeMotionOnReset is not finite or not positive.
50PARAM_ONLINEPLANNER_MAX_COMPUTATION_TIME_PATHThe parameter maxComputationTimePath is not finite or not positive.
51PARAM_ONLINEPLANNER_MAX_COMPUTATION_TIME_MOTIONThe parameter maxComputationTimeMotion is not finite or not positive.
52PARAM_ONLINEPLANNER_ADDITIONAL_AHEAD_PLANNING_TIMEThe parameter additionalAheadPlanningTime is not finite or not positive.
53PARAM_ONLINEPLANNER_ADDITIONAL_TRAJECTORY_DURATIONThe parameter additionalTrajectoryDuration is not finite or not positive.
54PARAM_ONLINEPLANNER_TIME_KEEP_PAST_TRAJECTORYThe parameter timeKeepPastTrajectory is not finite or is negative.
55PARAM_ONLINEPLANNER_NUM_SIMULATION_STEPSThe number of simulation steps is too high: the planning time is too high and/or the sample time is too low.
56PARAM_ASYNCPLANNER_TIMESTAMPThe input timestamp is not finite.
57PARAM_ASYNCPLANNER_TIMEOUT_INPUTThe input timeoutInput is not finite.
58PATHPLANNER_INITIAL_POSE_COLLISIONThe initial pose of the path planner collides with static obstacles.
59PATHPLANNER_OUT_OF_NODESThe path planner has run out of nodes and cannot sample new nodes anymore.
60MOTIONPLANNER_INITIAL_POSE_COLLISIONThe initial pose of the motion planner collides with static obstacles.
61MOTIONPLANNER_OUT_OF_NODESThe motion planner has run out of nodes and cannot sample new nodes anymore.
62MOTIONPLANNER_INFEASIBLE_TRAJECTORYThe final trajectory of the motion planner is dynamically infeasible.
63SEQUENTIALPLANNER_INCOMPLETE_MOTIONThe motion planner has not been executed, either due to a requested interrupt or because the path planner failed. The motion planner output is empty.
64ONLINEPLANNER_TIMESTAMP_NOT_INCREASINGThe input timestamp is not greater than the previous input timestamp for solving sequential problems.
65ASYNCONLINEPLANNER_OUTPUT_NOT_AVAILABLEThe output of the asynchronous online planner does not contain a planning result yet.
