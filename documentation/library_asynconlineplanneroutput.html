Default AsyncOnlinePlanner Output Bus

MPSV / Default AsyncOnlinePlanner Output Bus

Constructs the default output bus for the AsyncOnlinePlanner block. All elements are initialized to zero.

Output Ports

asyncOnlinePlannerOutput

Defines the output of the asynchronous online planner. The elements of the bus are listed in the following table.

ElementData TypeDescription
timestampdoubleMonotonically increasing timestamp in seconds (arbitrary time origin defined by the user) indicating the initial time point of the trajectory.
errorCodeuint8An error code indicating a planner error.
threadStateuint8State of the planning thread (0: offline, 1: standby, 2: running).
performedResetboolTrue if a reset has been performed, false otherwise.
trajectoryTruncatedboolTrue if the trajectory was truncated to fit the output buffer.
originLLAdouble [3]Geographical origin to which this output belongs, given as {lat, lon, alt}.
numTrajectoryPointsint32Number of points contained in the trajectory.
trajectorydouble [12][500]Resulting trajectory, where each element is given as {x, y, psi, u, v, r, X, Y, N, Xc, Yc, Nc}. The initial state and input is not inserted. The actual length of the trajectory is given by numTrajectoryPoints.
sampletimedoubleSample time of the trajectory data in seconds.
pathPlanner.numPosesint32Number of poses representing the path, i.e., the length of the path.
pathPlanner.pathdouble [3][100]Resulting path of the internal path planning problem, where each pose is given as {x, y, psi}. The actual length of the path is given by numPoses.
pathPlanner.goalReachedboolTrue if the goal is reached, false otherwise. The goal is reached when the final pose of the path equals the desired final pose of the planning problem.
pathPlanner.pathTruncatedboolTrue if the path was truncated to fit the output buffer.
pathPlanner.numberOfPerformedIterationsuint32Total number of iterations performed since the latest prepare step.
pathPlanner.timestampOfComputationUTCdoubleTimestamp (seconds of the day, UTC) indicating the time at which the solution was computed.
pathPlanner.costdoubleCost of the current solution: the total cost from the initial node to the final node of the path along the path.
motionPlanner.numPosesint32Number of poses representing the reference path, i.e., the length of the reference path.
motionPlanner.referencePathdouble [3][100]Resulting reference path of the internal motion planning problem, where each pose is given as {x, y, psi}. The actual length of the reference path is given by numPoses.
motionPlanner.goalReachedboolTrue if the goal is reached, false otherwise. The goal is reached when the final pose of the reference path equals the desired final pose of the planning problem.
motionPlanner.referencePathTruncatedboolTrue if the reference path was truncated to fit the output buffer.
motionPlanner.numberOfPerformedIterationsuint32Total number of iterations performed since the latest prepare step.
motionPlanner.timestampOfComputationUTCdoubleTimestamp (seconds of the day, UTC) indicating the time at which the solution was computed.
motionPlanner.costdoubleCost of the current solution: the total cost from the initial node to the final node of the reference path along the reference path.
