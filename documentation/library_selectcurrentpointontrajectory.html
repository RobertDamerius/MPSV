Select Current Point On Trajectory

MPSV / Select Current Point On Trajectory

Selects the current point on a given trajectory for a given time point. All times may originate from an arbitrary, user-defined time source. However, all times must be specified in seconds and must increase monotonically.

Input Ports

timeNow

The current time point used to query the point on the given trajectory.

trajectoryStartTimepoint

The time point that indicates the first data point of the trajectory.

trajectorySampletime

The temporal distance between two consecutive points of the trajectory.

trajectoryNumPoints

The number of points to be considered from the trajectoryData matrix.

trajectoryData

A 12-by-500 matrix containing up to 500 points of the trajectory, where each point represents the state-input vector [x; y; psi; u; v; r; X; Y; N; Xc; Yc; Nc].

Output Ports

success

True if timeNow lies within the temporal range of the trajectory and a point can be selected, false otherwise.

currentPoint

A bus containing the linearly interpolated state values and the zero-order-hold input values. The elements of the bus are listed in the following table.

ElementData TypeDescription
stateInterpolated.positionNorthdoubleThe north position (x) in meters.
stateInterpolated.positionEastdoubleThe east position (y) in meters.
stateInterpolated.orientationYawdoubleThe heading angle in radians.
stateInterpolated.velocityUdoubleThe body-fixed surge velocity in meters per second.
stateInterpolated.velocityVdoubleThe body-fixed sway velocity in meters per second.
stateInterpolated.velocityRdoubleThe angular velocity in radians per second.
stateInterpolated.tauXdoubleThe longitudinal force in the x direction of the body frame in newtons.
stateInterpolated.tauYdoubleThe lateral force in the y direction of the body frame in newtons.
stateInterpolated.tauNdoubleThe torque around the z axis of the body frame in newton meters.
controlInputZeroOrderHold.commandedTauXdoubleThe commanded longitudinal force in the x direction of the body frame in newtons.
controlInputZeroOrderHold.commandedTauYdoubleThe commanded lateral force in the y direction of the body frame in newtons.
controlInputZeroOrderHold.commandedTauNdoubleThe commanded torque around the z axis of the body frame in newton meters.

remainingTrajectoryDuration

The time from timeNow to the end of the trajectory.
