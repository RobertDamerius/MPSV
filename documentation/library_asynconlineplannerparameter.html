Default AsyncOnlinePlanner Parameter Bus

MPSV / Default AsyncOnlinePlanner Parameter Bus

Constructs the default parameter bus for the AsyncOnlinePlanner block. All elements are initialized to zero.

Output Ports

asyncOnlinePlannerParameter

Defines the parameters of the asynchronous online planner. The elements of the bus are listed in the following table.

ElementData TypeDescription
sequentialPlanner.geometry.collisionCheckMaxPositionDeviationdoubleMaximum position deviation for path subdivision during collision checking. Must be at least 0.01 m.
sequentialPlanner.geometry.collisionCheckMaxAngleDeviationdoubleMaximum angle deviation for path subdivision during collision checking. Must be at least 1 degree.
sequentialPlanner.geometry.verticesVehicleShapefloat [2][100]Vertex data of the vehicle shape. Multiple convex polygons are separated by non-finite vertices.
sequentialPlanner.geometry.skeletalPointsfloat [2][10]Skeletal points (body frame) at which the cost map is evaluated. Non-finite entries are ignored.
sequentialPlanner.costMap.resolutiondoubleResolution of the grid map (dimension of one cell). Must be greater than 1.0e-3.
sequentialPlanner.costMap.distanceScaledoubleScale factor (>= 0) for the obstacle distance cost in the cost map, applied as scale*exp(-decay*d^2), where d is the distance to the obstacle.
sequentialPlanner.costMap.distanceDecaydoubleDecay factor (> 0) for the obstacle distance cost in the cost map, applied as scale*exp(-decay*d^2).
sequentialPlanner.metric.weightPsidoubleWeighting of the heading angle (psi) in the distance metric.
sequentialPlanner.metric.weightSwaydoubleWeighting of the sway movement (heading angle with respect to the direction perpendicular to the direction of movement).
sequentialPlanner.metric.weightReverseScaledoubleWeighting of the sway and reverse movement (heading angle with respect to the line angle).
sequentialPlanner.metric.weightReverseDecaydoubleDecay factor (> 0) of the weighting function that weights the sway and reverse movement.
sequentialPlanner.model.matFdouble [36]3-by-12 coefficient matrix (row-major order) of the model nu_dot = F*n(nu) + B*tau.
sequentialPlanner.model.matBdouble [9]3-by-3 input matrix (row-major order) of the model nu_dot = F*n(nu) + B*tau.
sequentialPlanner.model.vecTimeconstantsXYNdouble [3]Time constants {TX, TY, TN} for the input force dynamics.
sequentialPlanner.model.vecTimeconstantsInputdouble [3]Time constants {Tf1, Tf2, Tf3} for the input filter dynamics.
sequentialPlanner.model.lowerLimitXYNdouble [3]Lower saturation values for the input vector u of the model nu_dot = F*n(nu) + B*tau.
sequentialPlanner.model.upperLimitXYNdouble [3]Upper saturation values for the input vector u of the model nu_dot = F*n(nu) + B*tau.
sequentialPlanner.pathPlanner.periodGoalSamplinguint32Iteration period for goal sampling; specifies how often the goal is used for sampling.
sequentialPlanner.motionPlanner.samplingRangePositiondoubleRange in meters for sampling the position around a given path.
sequentialPlanner.motionPlanner.samplingRangeAngledoubleRange in radians for sampling the angle around a given path.
sequentialPlanner.motionPlanner.periodGoalSamplinguint32Iteration period for goal sampling; specifies how often the goal is used for sampling.
sequentialPlanner.motionPlanner.sampletimedoubleSample time used for the fixed-step trajectory simulation.
sequentialPlanner.motionPlanner.maxInputPathLengthdoubleMaximum length (> 0) of the input path (x, y only). The input path is trimmed to this maximum length; the trimmed pose may be interpolated.
sequentialPlanner.motionPlanner.controller.maxRadiusXdoubleMaximum look-ahead distance for the longitudinal distance during pose control.
sequentialPlanner.motionPlanner.controller.maxRadiusYdoubleMaximum look-ahead distance for the lateral distance during pose control.
sequentialPlanner.motionPlanner.controller.maxRadiusPsidoubleMaximum look-ahead distance for the angular distance during pose control.
sequentialPlanner.motionPlanner.controller.minRadiusPositiondoubleMinimum look-ahead distance for the position during pose control. The guidance law limits the radius according to nearby obstacles, but it never falls below this value.
sequentialPlanner.motionPlanner.controller.matKdouble [36]3-by-12 control gain matrix (row-major order) for pose control.
sequentialPlanner.motionPlanner.regionOfAttraction.rangePosedouble [3]Pose box constraints of the region of attraction.
sequentialPlanner.motionPlanner.regionOfAttraction.rangeUVRdouble [3]Velocity box constraints of the region of attraction.
sequentialPlanner.motionPlanner.regionOfAttraction.rangeXYNdouble [3]Force range {dX, dY, dN}. A given force must lie in the range {[-dX, dX], [-dY, dY], [-dN, dN]} to be inside the region of attraction.
onlinePlanner.maxComputationTimePathOnResetdoubleMaximum computation time in seconds for path planning after a reset.
onlinePlanner.maxComputationTimeMotionOnResetdoubleMaximum computation time in seconds for motion planning after a reset.
onlinePlanner.maxComputationTimePathdoubleMaximum computation time in seconds for path planning.
onlinePlanner.maxComputationTimeMotiondoubleMaximum computation time in seconds for motion planning.
onlinePlanner.additionalAheadPlanningTimedoubleAdditional time in seconds added to the estimated computation time to obtain the future time point from which the next planning problem is started. Must be greater than zero.
onlinePlanner.additionalTrajectoryDurationdoubleAdditional time added to the ahead planning time (= execution time + additional ahead planning time) to obtain the minimum time duration of a trajectory. Must be greater than zero.
onlinePlanner.timeKeepPastTrajectorydoubleTime in seconds to keep from a past trajectory. The past data of the previous trajectory is inserted at the beginning of a new solution. Inserting past data helps to handle imperfect time synchronization between the trajectory generator and the user of the trajectory data.
