Simulink block

AutoTune AsyncOnlinePlanner

MPSV / AutoTune AsyncOnlinePlanner

Calculates all tuning parameters for the AsyncOnlinePlanner based on the given vehicle parameters and one intuitive tuning parameter.

Input Ports

controlEffort

The amount of control effort in the range (0, 1] used to drive the vehicle in a steady state in the longitudinal direction. A low value makes the vehicle move slower; a high value makes the vehicle move faster.

geometry_verticesVehicleShape

A 2-by-100 matrix of type double containing the vertex list of multiple convex polygons, where each polygon is separated by non-finite values. All non-finite values of the matrix are ignored. Example for a simple rectangle of 10 by 2 meters: [5 -5 -5 5 nan(1,96); 1 1 -1 -1 nan(1,96)]

geometry_collisionCheckMaxPositionDeviation

Maximum position deviation for path subdivision during collision checking. Must be at least 0.01 m.

geometry_collisionCheckMaxAngleDeviation

Maximum angle deviation for path subdivision during collision checking. Must be at least 1 degree (0.0174532925199433 radians).

model_matF

3-by-12 coefficient matrix (row-major order) of the model nu_dot = F*n(nu) + B*tau.

model_matB

3-by-3 input matrix (row-major order) of the model nu_dot = F*n(nu) + B*tau.

model_vecSatXYN

Absolute saturation values for the input vector.

model_vecTimeconstantsXYN

Time constants {TX, TY, TN} for the input force dynamics.

model_vecTimeconstantsInput

Time constants {Tf1, Tf2, Tf3} for the input filter dynamics.

timing_sampletime

Sample time used for the fixed-step trajectory simulation.

timing_maxComputationTimePath

Maximum computation time in seconds for path planning.

timing_maxComputationTimeMotion

Maximum computation time in seconds for motion planning.

metric_weightPsi

Weighting (> 0) of the heading angle (psi) in the distance metric.

metric_weightSway

Weighting (>= 0) of the sway movement (heading angle with respect to the direction perpendicular to the direction of movement).

metric_weightReverseScale

Weighting (>= 0) of the sway and reverse movement (heading angle with respect to the line angle).

metric_weightReverseDecay

Decay factor (> 0) of the weighting function that weights the sway and reverse movement.

metric_distanceScale

Scale factor (>= 0) for the obstacle distance d cost in the cost map: scale*exp(-decay*d^2).

metric_distanceDecay

Decay factor (> 0) for the obstacle distance d cost in the cost map: scale*exp(-decay*d^2).

Output Ports

asyncOnlinePlannerParameter

Defines the parameters of the asynchronous online planner. This output is identical to the output of the Default AsyncOnlinePlanner Parameter Bus block.

Block Parameters

The following table lists all block parameters.

Parameter NameDescription
periodGoalSamplingGoal sampling period used for path and motion planning. Default: 30.

Details

The following subsections describe how the auto-tuner derives the tuning parameters empirically.

Timings

The computation time after a reset is set to 20 percent of the maximum computation times. The additional ahead planning time is max(0.2, 10*sampletime).

Skeletal Points

The skeletal points are the two points [xmax; ymean] and [xmin; ymean], where xmax and xmin are the maximum and minimum x coordinates of the vehicle shape vertices, respectively, and ymean is the average y coordinate of the vehicle shape vertices.

Cost Map Resolution

The resolution is set to half of the smallest vehicle dimension.

matK, maxRadiusX, maxRadiusY, maxRadiusPsi

The controller gain and the guidance radii are coupled. First, the longitudinal stop distance is calculated based on the maximum force according to the saturation value of the model. The desired radius in x direction is then set to 1.2 * stopDistance. Afterwards, the controller gain is adjusted in a bisection search until the control effort would match the specified controlEffort value. The guidance radii are calculated based on the controller gain matrix and the steady-state force and velocity.

minRadiusPosition

This value is the smallest of maxRadiusX, maxRadiusY, and the minimum vehicle dimension.

rangePose, rangeUVR, rangeXYN

The ranges are calculated based on the vehicle dimension, the maximum velocity, and the maximum force, e.g., 5 percent of the maximum value. For the sway speed, 10 percent is used. The angular range is fixed to 5 degrees.

samplingRangePosition, samplingRangeAngle

The angular sampling range around a path is fixed to 30 degrees. The positional range is calculated based on the guidance radius.

maxInputPathLength

This length is calculated from the maximum velocity, the total replanning time, and the greatest guidance radius, such that a subgoal pose is not within the guidance radius within the total replanning time.

maxUVR (informational only)

This value represents the maximum velocity that would be reached when driving with the maximum force according to the model saturation value. Each degree of freedom is considered separately, assuming that matB of the model is mainly diagonal.

steadyStateUVR (informational only)

This value represents the steady-state velocity that is reached when driving with a nominal force of controlEffort*satXYN, where satXYN is the input saturation value of the model. Each degree of freedom is considered separately, assuming that matB of the model is mainly diagonal.
