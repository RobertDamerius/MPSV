Default PathPlanner Parameter Bus

MPSV / Default PathPlanner Parameter Bus

Constructs the default parameter bus for the PathPlanner block. All elements are initialized to zero.

Output Ports

pathPlannerParameter

Defines the parameters of the path planner. The elements of the bus are listed in the following table.

ElementData TypeDescription
costMap.resolutiondoubleResolution of the grid map (dimension of one cell). Must be greater than 1.0e-3.
costMap.distanceScaledoubleScale factor (>= 0) for the obstacle distance cost in the cost map, applied as scale*exp(-decay*d^2), where d is the distance to the obstacle.
costMap.distanceDecaydoubleDecay factor (> 0) for the obstacle distance cost in the cost map, applied as scale*exp(-decay*d^2).
geometry.collisionCheckMaxPositionDeviationdoubleMaximum position deviation for path subdivision during collision checking. Must be at least 0.01 m.
geometry.collisionCheckMaxAngleDeviationdoubleMaximum angle deviation for path subdivision during collision checking. Must be at least 1 degree.
geometry.verticesVehicleShapefloat [2][100]Vertex data of the vehicle shape. Multiple convex polygons are separated by non-finite vertices.
geometry.skeletalPointsfloat [2][10]Skeletal points (body frame) at which the cost map is evaluated. Non-finite entries are ignored.
metric.weightPsidoubleWeighting of the yaw angle in the distance metric.
metric.weightSwaydoubleWeighting of the sway movement (heading angle with respect to the direction perpendicular to the direction of movement).
metric.weightReverseScaledoubleWeighting of the sway and reverse movement (heading angle with respect to the line angle).
metric.weightReverseDecaydoubleDecay factor (> 0) of the weighting function that weights the sway and reverse movement.
pathPlanner.periodGoalSamplinguint32Iteration period for goal sampling; specifies how often the goal is used for sampling.
pathPlanner.maxComputationTimedoubleMaximum computation time in seconds allowed before leaving the iteration loop.
