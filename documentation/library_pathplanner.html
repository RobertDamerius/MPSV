Simulink block

PathPlanner

MPSV / PathPlanner

Solves the path planning problem between an initial pose and a final pose. The computation time budget that is allocated to the planner is set via the parameter input.

All timestamps may originate from an arbitrary, user-defined time source. However, all times must be specified in seconds and must increase monotonically.

Input Ports

pathPlannerInput

The input bus of the path planner, constructed with the Default PathPlanner Input Bus block.

pathPlannerParameter

The parameter bus of the path planner, constructed with the Default PathPlanner Parameter Bus block.

Output Ports

pathPlannerOutput

The output bus of the path planner, defined by the Default PathPlanner Output Bus block.

Block Parameters

The following table lists all block parameters.

Parameter NameDescription
maxNumNodesMaximum number of nodes used in the tree.
maxNumSamplesMaximum number of random samples generated in advance.
maxNumCellsMaximum number of cells in the cost map (LUT).
