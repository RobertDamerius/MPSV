Default AsyncOnlinePlanner Input Bus

MPSV / Default AsyncOnlinePlanner Input Bus

Constructs the default input bus for the AsyncOnlinePlanner block. All elements are initialized to zero.

Output Ports

asyncOnlinePlannerInput

Defines the input of the asynchronous online planner. The elements of the bus are listed in the following table.

ElementData TypeDescription
timestampdoubleMonotonically increasing timestamp in seconds (arbitrary time origin defined by the user) indicating the initial time point corresponding to initialStateAndInput.
enableboolTrue if the asynchronous online planner should be enabled, false if it should go into standby mode.
resetboolTrue if the asynchronous online planner should be reset. The reset is guaranteed to be performed before the next internal solve operation of the planner.
originLLAdouble [3]Geographical origin to which this input belongs, given as {lat, lon, alt}.
initialStateAndInputdouble [12]Initial state and input, given as {x, y, psi, u, v, r, X, Y, N, Xc, Yc, Nc}.
finalPosedouble [3]Final pose, given as {x, y, psi}.
samplingBoxCenterPosedouble [3]Center pose of the sampling box, given as {x, y, psi}. The angle specifies the orientation of the box.
samplingBoxDimensiondouble [2]Dimensions of the sampling box along its major and minor axes.
verticesStaticObstaclesfloat [2][8000]Vertex data of the static obstacles. Multiple convex polygons are separated by non-finite vertices.
