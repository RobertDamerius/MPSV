AsyncOnlinePlanner

MPSV / AsyncOnlinePlanner

Solves the online sequential motion planning problem in a parallel thread that runs asynchronously. The computation time budgets of the internal planners are configured via the parameter input.

All timestamps may originate from an arbitrary, user-defined time source. However, all times must be specified in seconds and must increase monotonically.

Input Ports

asyncOnlinePlannerInput

The input bus of the asynchronous online planner, constructed with the Default AsyncOnlinePlanner Input Bus block.

asyncOnlinePlannerParameter

The parameter bus of the asynchronous online planner, constructed with the Default AsyncOnlinePlanner Parameter Bus block.

Output Ports

asyncOnlinePlannerOutput

The output bus of the asynchronous online planner, defined by the Default AsyncOnlinePlanner Output Bus block.
